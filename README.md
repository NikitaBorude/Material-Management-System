# Material Management System (MMS)

## Project Overview

The Material Management System (MMS) is a web-based application developed to manage products, suppliers, purchases, sales, and stock information efficiently. It helps maintain material records and simplifies daily inventory management activities.

## Technologies Used

* **Backend:** Java, Spring Boot
* **Frontend:** HTML, CSS
* **Database:** MySQL
* **Database Tool:** MySQL Workbench
* **Build Tool:** Maven
* **IDE:** Spring Tools / Eclipse

## Features

* User Login and Authentication
* Dashboard with stock information
* Add, View, Edit, Update, and Delete Products
* Supplier Management
* Purchase Management
* Sales Management and Billing
* Invoice Generation
* Low Stock Alerts
* Reports and Inventory Tracking

## Database

The project uses MySQL to store and manage application data.

**Database Name:** `mms_db`

## How to Run the Project

1. Clone or download this repository.
2. Open the project in Spring Tools or Eclipse.
3. Configure MySQL and create the required database.
4. Configure your local database credentials in `application.properties`.
5. Build the project using Maven.
6. Run the Spring Boot application.
7. Open a browser and visit `http://localhost:8080` (or the configured application port).
